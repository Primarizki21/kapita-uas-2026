# Public dataset candidates for a Topic 1 study distinct from SocioMathLLM

**Prepared:** 2026-11-23. **Scope:** reproducible, no-login (or clearly flagged) public datasets for a six-student group with no GPU budget, in support of the Tugas 2 requirement to collect the syntax and data used in the analysis and the UAS requirement to analyse a topic *similar but not identical* to Hwang and Utami's SocioMathLLM (DOI `10.1109/TLT.2026.3677266`, as cited in the course brief `knowledge/Tugas 2 dan UAS Kapita Selekta Sains Data Gasal 2026-2027.md`, lines 17–32).

**Design principle for distinctness.** SocioMathLLM is a *three-module generative pipeline* (image contextualisation → profile-based candidate selection → four-competency socialisation prompt) evaluated with BLEU/METEOR/ROUGE-L/BLEURT/BERT scores and teacher/LLM judgement on GPT-4o output. A defensible but distinct study keeps one piece of the problem — mathematical word problems (MWPs) — and changes the method and the data modality: e.g. **CPU-only structural analysis of existing MWP corpora** (equation templates, numeric perturbation, grade level, language/cultural adaptation) instead of image-conditioned generation with a paid API. The comparison-topic rows in section (d) satisfy brief rule 3 ("Carilah topik dan data yang serupa pada ketiga topik tersebut") by providing analogous data for Topics 2–4.

## Verification legend and hash policy

- **[V-API]** verified by direct fetch of the Hugging Face datasets API / dataset-viewer API on 2026-11-23.
- **[V-WEB]** verified by `web_search` against the official project page, paper page or repository; not re-downloaded here.
- **[V-GET]** verified by direct HTTP GET/HEAD on 2026-11-23; byte counts below are the observed `size_download` values.
- **[UNVERIFIED]** the URL/licence/data could not be confirmed; do not rely on it without a further check.

**SHA-256.** Hugging Face stores large files in Git LFS and publishes the file's SHA-256 as `lfs.oid` in the tree API. Where available, the hash below is that published value (not a guess). Everything else (GitHub raw files, WHO XLSX, ZIP/tar archives, small non-LFS HF files) has **no publisher-published SHA-256**: the honest protocol is to pin the URL to an immutable commit/revision where possible, download once, compute `sha256sum`, and record that value in the group's metrics/ledger. Example for GSM8K:

```bash
# Published SHA-256 values (HF LFS oid), see [V-API] tree URL in row 1
curl -Ls 'https://huggingface.co/api/datasets/openai/gsm8k/tree/main/main?recursive=true&expand=true' \
  | jq -r '.[] | [.path, .lfs.oid] | @tsv'
curl -L -o train.parquet \
  'https://huggingface.co/datasets/openai/gsm8k/resolve/740312add88f781978c0658806c59bc2815b9866/main/train-00000-of-00001.parquet'
sha256sum train.parquet   # expect ea82612ea9582142387730c793eb67d3b12849002bc0b7fa6f8efafa7351419d
```

All commands below are download/syntax only; they were not executed as part of an analysis, and no files were added to the repository by this note.

Smallest setup cost, MIT, immutable commit URL, and both files carry published SHA-256. **Reproducibility note:** pin HF revision `740312add88f781978c0658806c59bc2815b9866`, download only `main/train-*.parquet` (2.3 MB) and `main/test-*.parquet` (0.4 MB), verify the two `lfs.oid` hashes above, split the six students into three pairs (equation extraction, perturbation design, metric implementation), fix a random seed, and log per-run hashes/metrics. 2. **BEIR / SciFact** — comparison-topic (4) analogue with the best licence clarity after reading AllenAI's own `LICENSE.md`. 5.2 MB of Parquet and CPU BM25 are enough for a full query-expansion experiment. **Reproducibility note:** do **not** use the UKP ZIP (timed out here); `hf download BeIR/scifact --repo-type dataset` at revision `b3b5335604bf5ee3c4447671af975ea25143d4f5`, verify the two corpus/query SHA-256 values from the tree API, keep qrels separate from any pseudo-relevance feedback (no leakage), record `nDCG@10`/`Recall@10` for original vs expanded queries, and attribute claims (CC BY 4.0) and abstracts (ODC-By 1.0) separately.
